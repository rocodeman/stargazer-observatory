## 项目简介

![三体首页观测界面](docs/homepage.jpg)

在线体验：[三体天文观测模拟器](https://stargazer-gbqurilt.manus.space)

> 一款以“三体”叙事氛围为灵感的全屏天文观测模拟器。用户可以拖动 3D 天球探索星空、观测太阳系天体，并通过五项叙事任务体验三颗太阳、宇宙广播、隐藏目标搜索与昼夜观测。


## 核心功能

| 功能模块 | 说明 |
| --- | --- |
| 3D 天球观测 | 使用科学星点数据呈现星空，支持鼠标拖拽旋转视角、星座连线、中文名称、英文缩写和天体标注。 |
| 89 个星座 | 首屏加载约 3,000 个高亮星点与 20 个重点星座，并支持按需加载完整 89 个星座目录。 |
| 天体交互 | 点击太阳、月球、行星及部分深空天体，可以查看距离、视星等、类型和简介等信息。 |
| 昼夜切换 | 通过太阳/月亮控制切换观测环境，影响星空视觉表现和部分任务的可用条件。 |
| 视觉强度 | 支持“柔和显示”和“全部高亮”两种星座视觉强度。 |
| 三体模拟 | 在“三个太阳”任务中进入独立的 Three.js 三星异常轨道模拟，支持拖拽、缩放、暂停和调速。 |
| 太阳系运转 | 以 3D 轨道仪表观察太阳系运行，并承载“宇宙广播”流程。 |
| 星际旅行 | 从地球前往目标行星，体验飞船视角、航行日志和抵达后的行星环绕观察。 |
| 截图任务 | 使用相机按钮保存带本地时间戳的观测截图。 |
| 流星雨效果 | 任务完成时提供流星雨反馈；五项任务全部完成后持续播放并显示终局信息。 |

## 五项互动任务

任务状态会保存在浏览器本地存储中，跨页面跳转后仍然保持。每项任务右侧的“提示”按钮会在屏幕中央显示线索卡；点击文字关闭提示后即可继续观测操作。点击“重玩”可以清除任务完成状态、阶段授权、进度、临时庆祝效果和终局信息。

| 顺序 | 任务 | 完成条件 | 中央提示线索 |
| --- | --- | --- | --- |
| 1 | 三个太阳 | 从首页点击三个太阳外观的虚拟天体，进入 `/solar-triad` 完成异常轨道观测，并通过“完成观测并返回”回到观测站。 | 点击任务面板，打开三颗异常太阳的运行记录。 |
| 2 | 宇宙广播 | 必须在白天观测模式下点击太阳，进入太阳系页面后再次点击太阳，完成逐字通信、“不要回答”三次和最终“回答”流程。 | 不要在黑夜呼喊；等待白昼，寻找太阳并让信号继续传播。 |
| 3 | 科学家的葬礼 | 在全屏星空中寻找三位低对比度的人形目标；第四位只能通过点击任务面板发现。每发现一位目标，其轮廓会立即从画面中移除，提示会明确显示还需发现的人数。 | 四个永远沉默的科学家散落在观测视野中，请检查整片天空。 |
| 4 | 倒计时 | 点击相机按钮完成整页截图，图片附带年月日、小时、分钟和秒数时间戳。 | 让相机记住此刻，时间会留下证据。 |
| 5 | 为你闪耀 | 仅在夜间观测模式下，将视觉强度从“柔和显示”切换至“全部高亮”达到当前设定阈值；普通点击不会计入任务。 | 在夜幕下切换至全部高亮，直到信号稳定。 |

## 页面与路由

| 路由 | 页面用途 |
| --- | --- |
| `/` | 三体主观测站、全屏 3D 天球、任务面板和天体详情。 |
| `/solar-triad` | 三颗太阳的异常轨道 Three.js 模拟。 |
| `/solar-system` | 太阳系 3D 运转仪表和宇宙广播任务流程。 |
| `/travel/:planetId` | 地球至目标行星的沉浸式星际旅行与抵达观察。 |

## 技术栈

项目使用 React 19、TypeScript、Vite、Three.js、Wouter、Tailwind CSS 4 和 `html2canvas` 构建。Three.js 负责三体轨道、太阳系和行星近景等 3D 场景，自定义 CSS 负责仪器舱风格界面。

## 数据与状态

项目是静态前端应用，不依赖后端数据库。任务进度、昼夜授权和截图完成状态主要通过浏览器的 `localStorage` 与 `sessionStorage` 管理。

## 本地运行

### 环境要求

建议使用 Node.js 22，并安装 pnpm；安装依赖后即可启动开发服务器。

```bash
git clone https://github.com/rocodeman/stargazer-observatory.git
cd stargazer-observatory
pnpm install
pnpm dev
```

启动后访问终端输出的本地地址，通常为 `http://localhost:3000`。

### 类型检查与构建

```bash
pnpm check
pnpm build
pnpm preview
```

其中，`pnpm check` 用于执行 TypeScript 检查，`pnpm build` 用于生成生产构建产物，`pnpm preview` 用于在本地预览构建结果。
